# Git Tehtävä

## 1.      Mitä versionhallinnalla tarkoitetaan
 \- Versionhallinta on tapa seurata ja hallita projektien / tiedostojen eri versioita.

## 2.      Mikä on Git versiohallinta ja mikä on sen historia
 \- Git on järjestelmä jolla seurataan ja hallitaan tiedostojen muutoksia ja eri versioita. Historiaa: Gitin kehitti Linus Torvalds vuonna 2005 Linuxin tarpeisiin. Yksi yleisimmistä versionhallinta ohjelmista

## 3.      Git\:n käyttöönotto
 \- Asenna git, aseta oma nimi ja sähköposti, luo tai kloonaa git repositorio

## 4.      Git\:n tärkeimmät komennot
 \- **git init** (Luo uuden repositorion), **git add** (Lisää muutokset indeksiin), **git commit** (Tallentaa muutokset), **git push** (Lähettää muutokset etärepositorioon) ja **git pull** (Hakee uusimmat muutokset etärepositoriosta)

## 5.      Git commit prosessi
 \- Muutokset tiedostoon à git add à git  commit ja muutokset tallentuvat. Ilman git add, git ei ota uusia tai muokattuja tietoja committiin.

## 6.      Muutoksen peruminen
 \- **Git restore** – Peruu tiedoston tekemät muutokset
    **Git restore -- staged** – Poistaa tiedoston commitista mutta säilyttää muutokset
    **Git revert** – Peruu aiemman commitin tekemällä uuden commitin
